# Session 02 - Git et GitHub

Réponses rédigées avec mes propres mots, puis comparées au corrigé de la page.

## 1. Index et commit

**Réponse :**

L’index est une zone où l’on prépare les fichiers avant de les enregistrer dans un commit. Le commit sauvegarde un ensemble de modifications dans l’historique du projet.

## 2. Branche et tag

**Réponse :**

Une branche permet de travailler sur une ligne de développement. Un tag sert à identifier un point précis de l’historique, par exemple une version ou une étape du projet.

## 3. Le fichier .env

**Réponse :**

Le fichier `.env` contient la configuration de l’application, comme les informations de connexion à la base de données. Il peut contenir des informations sensibles, donc il ne doit pas être envoyé sur GitHub.

## 4. Le dossier vendor/

**Réponse :**

Le dossier `vendor/` contient les dépendances PHP installées par Composer. Il est généralement exclu de Git parce qu’on peut le recréer avec la commande `composer install`.

## 5. Git Credential Manager

**Réponse :**

Git Credential Manager permet de gérer et de conserver de manière sécurisée les identifiants utilisés pour se connecter aux services Git, comme GitHub, afin d’éviter de saisir ses identifiants à chaque opération.
